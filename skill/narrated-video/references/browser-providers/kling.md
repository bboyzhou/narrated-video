# 可灵网页 I2V

## Inspect

打开可灵官方创作页，确认登录与 Image to Video 功能。核实当前账号是否仍有可用于本次请求的赠送免费额度，并区分免费额度、会员额度和付费余额。无法确认扣费来源时返回 `cost_unconfirmed`。

## Submit

上传源图、填写动作提示并选择请求支持的参数。提交前再次确认只消耗已核实的免费额度；提交后保存任务 ID、任务详情 URL 或唯一任务卡特征。不要因页面曾宣传免费而跳过当前额度检查。

## Query / Download

使用已保存关联在历史任务中查询状态。完成后下载原视频并记录实际模型、尺寸、水印及下载条件。平台要求升级或付费才能下载满足交付要求的文件时返回 `download_unavailable`，保留原图回退。
