# PixVerse 网页 I2V

## Inspect

打开 PixVerse 官方创作网页，确认当前账号已登录并能进入 Image to Video。读取页面当前显示的免费积分、所选模型、时长、画幅、清晰度、水印和本次生成费用。只有页面明确显示赠送的免费余额可覆盖，且不会扣现金、会员额度或付费余额，才返回 `available`；网页额度不代表 API 额度。

## Submit

进入 Image to Video，上传动作请求中的源图，填写 motion prompt 和必要的 negative prompt，按请求选择时长、画幅和运动强度。提交前再次核对只会消耗已确认的免费积分。提交后从任务卡、历史记录或详情页取得远端任务 ID、URL 或可唯一识别的时间与提示词摘要。

## Query / Download

在生成记录中按已保存的远端关联查找任务，区分排队、生成、失败与完成。完成后使用平台的原视频下载功能；记录页面显示的模型、水印和下载条件。若只能取得预览链接或页面无法保存本地文件，返回 `download_unavailable`。
