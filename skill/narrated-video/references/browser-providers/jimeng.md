# 即梦网页 I2V

## Inspect

打开即梦官方创作页，确认登录并进入视频生成／图生视频。读取当前账号页面显示的积分来源、本次参数费用、可用时长与比例。只有能确认使用赠送的免费额度，且不会扣现金、会员额度或付费余额时返回 `available`；二维码登录、实名或验证码要求分别记录，不代替用户完成。

## Submit

上传请求中的源图并填写平台中性的动作提示，选择匹配的画幅、时长和运动强度。提交前核对费用，提交后从任务卡或生成记录保存可唯一关联的信息。长时间排队时返回 `queued` 和页面可见的等待提示，不停留在页面轮询。

## Query / Download

从生成记录定位原任务并读取状态。完成后使用平台提供的下载入口保存原视频，记录页面显示的模型名称、水印和使用条件。UI 无法可靠定位任务时返回 `ui_changed` 或 `not_found`，不重新提交。
